Bill Splitter
Project Overview

This is a simple Tip Calculator and Bill Splitter web application built using React + Vite.
It allows users to:
-Enter a bill amount
-Select or enter a custom tip percentage
-Enter number of people
-See live calculated results (no button click needed)

The app updates results instantly as the user types.

Features
-Live calculation of tip and total bill
-Bill splitting among multiple people
-Preset tip buttons (10%, 15%, 20%)
-Custom tip input option
-Inline validation for inputs
-Reset button to clear all values
-Responsive design for mobile and desktop

Tech Stack:
-React (Frontend library)
-Vite (Build tool)
-JavaScript (Logic)
-CSS (Styling)

Project Setup:
1. Clone the repository
git clone <your-repo-link>
2. Move into project folder
cd BillSplitter
3. Install dependencies
npm install
4. Run the project locally
npm run dev

After this, open the link shown in terminal (usually):

http://localhost:5173
Build for Production
To create a production build:
npm run build

The output will be generated in the dist folder.

Project Purpose:
This project was built as part of a frontend assessment to demonstrate:
-React fundamentals
-State management using useState
-Form handling and validation
-UI/UX thinking
-Responsive frontend design
